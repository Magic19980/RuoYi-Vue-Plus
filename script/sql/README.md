# 科室管理 SQL 执行说明

## 新环境

按顺序执行 `department_management.sql`。该文件包含科室管理模块的完整建表和基础初始化数据。

## 已有环境

先确认历史脚本已执行，再按版本号顺序执行 `migration/` 目录下的增量脚本，例如：

`migration/department_management_20260824_task_model.sql`

当前仍处于开发阶段、无历史业务数据，增量脚本允许直接删除已废弃字段和表。人工单“状态”“数据确认状态”以及独立日报工作日配置表已在迁移脚本中清理，新的日报工作日与提醒统一由任务分配维护。

## 规则

- 初始化脚本面向全新数据库，不要在生产环境反复执行结构性修改。
- 增量脚本使用 `information_schema` 判断字段和索引，兼容当前 MySQL 版本，不使用 `ADD COLUMN IF NOT EXISTS`。
- 每次新增结构先增加迁移脚本，再同步更新初始化脚本。
